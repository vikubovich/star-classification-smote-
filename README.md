## О проекте
 
Реальные табличные датасеты часто слишком маленькие или сильно несбалансированные, и из-за этого модели плохо обобщают. В проекте проверяется, как аугментация методом SMOTE влияет на качество классических ML-моделей в такой ситуации.
 
**Задача:** многоклассовая классификация звёзд по спектральному классу.
 
## Данные
 
[Star Dataset (Kaggle)](https://www.kaggle.com/datasets/deepu1109/star-dataset): 240 объектов, пропусков нет.
 
- **Признаки:** температура, светимость, радиус, абсолютная звёздная величина, тип звезды, цвет звезды
- **Целевая переменная:** `Spectral Class`. Классы G и K удалены, потому что в них слишком мало объектов. Осталось 5 классов: M, B, A, F, O
- Классы сильно несбалансированы, поэтому датасет хорошо подходит для эксперимента
## Что сделано
 
1. **EDA:** распределения признаков по классам, поиск выбросов (boxplot), корреляционная матрица
2. **Обучение 8 моделей на исходных данных:** Logistic Regression, Decision Tree, KNN, MLP, Random Forest, SVC (RBF), Gaussian Naive Bayes, Gradient Boosting. Оценка на кросс-валидации, матрицы ошибок, кривые обучения
3. **Подбор гиперпараметров** лучшей модели с помощью байесовской оптимизации (Optuna, TPE)
4. **Аугментация SMOTE:** по 1000 объектов в каждом классе, затем повторное обучение тех же 8 моделей
5. **Сравнение результатов** до и после аугментации
6. **Эксперименты с pipeline:** PCA для понижения размерности и разный порядок шагов (стандартизация → PCA → модель и PCA → стандартизация → модель)
## Результаты
 
Accuracy на кросс-валидации:
 
| Модель | До аугментации | После SMOTE |
|---|---|---|
| Logistic Regression | 0.8885 | 0.9270 |
| Decision Tree | 0.8969 | 0.9504 |
| KNN | 0.8799 | 0.9898 |
| MLP | 0.9315 | **0.9956** |
| Random Forest | **0.9399** | 0.9860 |
| SVC (RBF) | 0.9228 | 0.9574 |
| Gaussian NB | 0.7637 | 0.7984 |
| Gradient Boosting | 0.9271 | 0.9399 |
 
**Основные выводы:**
- После SMOTE accuracy выросла у **всех** моделей
- Разрыв между точностью на обучении и на кросс-валидации стал заметно меньше, то есть модели лучше обобщают
- Лучшая модель до аугментации — Random Forest (0.94), после аугментации — MLP (≈0.99)
- PCA вместе со стандартизацией немного улучшил MLP (0.9890 → 0.9920), но ухудшил Random Forest (0.9149 → 0.8298)
- Порядок шагов в pipeline важен: если делать PCA до стандартизации, качество сильно падает у обеих моделей
## Заключение
 
Работа показала, что аугментация табличных данных особенно полезна в двух ситуациях: когда выборка очень маленькая (меньше 1000 строк) и когда классы сильно несбалансированы. В таких условиях модель склонна запоминать шум и плохо строит границы для редких классов, поэтому чаще на них ошибается.
 
SMOTE создаёт правдоподобные синтетические объекты редких классов на основе их ближайших соседей и тем самым заполняет «пустые» области пространства признаков. После аугментации:
 
- метрики выросли у всех восьми моделей;
- у большинства моделей сократился разрыв между точностью на обучении и на кросс-валидации, а у некоторых он стал почти нулевым, то есть модели стали лучше работать на новых данных;
- лучшей моделью стал MLP с подобранными гиперпараметрами;
- понижение размерности через PCA подходит не всем моделям, а порядок шагов в pipeline сильно влияет на результат: стандартизация должна идти до PCA.
Итог: SMOTE — эффективный инструмент для повышения качества моделей на маленьких несбалансированных табличных данных.
